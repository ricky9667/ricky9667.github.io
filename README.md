# HUSH Cubing Apps

Landing page for Ricky Hu's Rubik's Cube and speedcubing projects, served by GitHub Pages at <https://apps.ricky-hu.com/>.

A static site with no build step:

```
index.html        markup and the inline SVG icon sprite
css/styles.css    all styles (tokens, layout, components, animations)
js/main.js        scroll reveal, header brand long-press, card glow, scramble
assets/logo/      site logo, favicon sizes and the WCA mark
assets/tech/      tech-stack icons shown on the project cards
```

To preview locally, serve the folder and open <http://localhost:4173/>:

```bash
python3 -m http.server 4173
```
